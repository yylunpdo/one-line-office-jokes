A make.fun entry for the **One-Line Office Jokes** bounty: one line that
makes office life funny — built on one real office detail, the reply-all
chain nobody can escape, and landing sharp: asking to leave the thread
is exactly what gets you promoted to running it.

## The joke

> I replied-all 'please remove me from this thread' and got promoted to thread manager by 47 strangers who also replied-all.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single joke to `/output/entry.txt` (UTF-8,
one line, inside the 1–199 character gate).

```sh
python3 main.py
cat /output/entry.txt
```
